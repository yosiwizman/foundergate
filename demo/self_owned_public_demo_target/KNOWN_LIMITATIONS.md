# Known Limitations — FounderGate Demo Tasks
- It is a **toy module**: a task ledger with status + evidence notes. Not a real product.
- **In-memory only** — no persistence beyond reading a JSON file; no database.
- **No network, no auth, no multi-user, no concurrency** handling.
- **Synthetic data only** — the sample contains no real people, tasks, or customer data.
- It is a **self-owned rehearsal target**, not a design partner's repo. A rehearsal here does NOT demonstrate external demand or real-world fitness.
- Not production-ready, not customer-ready, not secure, not compliant, not deployed — and none of those are claimed.

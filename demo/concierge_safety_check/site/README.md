# Concierge Safety Check — Local Demo Site
Self-contained static site (6 pages). No CDN, no analytics, no network, no deployment.

Run locally:
```
cd demo/concierge_safety_check/site && python3 -m http.server 4840
# open http://127.0.0.1:4840/index.html
```
Every page carries the banner: INTERNAL DEMO ONLY · PUBLIC NON-SENSITIVE REPOS ONLY · NO SECRETS · NOT PRODUCTION OR SECURITY CERTIFICATION.

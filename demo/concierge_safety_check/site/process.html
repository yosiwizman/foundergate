The 9 stages

  1. Qualify — public repo, non-sensitive, small objective.
  2. Intake — 7 questions (repo, objective, paths to avoid, no-secrets confirm, decision wanted, window, recipient).
  3. Repo suitability screen — verify public + non-sensitive; stop if sensitive.
  4. Scope lock — objective + path limits + hard cost cap, one line.
  5. Governed run — isolated worktree, tests, cost cap, path allowlist, evidence capture.
  6. Independent review — Checker + separate Gate Advisor, read-only.
  7. Evidence note — SHA, changed files, tests, verdicts, decision, limits.
  8. Conservative decision — INTERNAL_DEMO_ONLY or SUITABLE_FOR_CONCIERGE_TRIAL_WITH_LIMITS. Never SHIP.
  9. Handback + debrief — deliver the note; ask the one honest pricing question.

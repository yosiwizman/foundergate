PHASE 2 — HARD DEADLINE LAW

The original run deadline is immutable.

For every worker invocation, compute:

remaining_run_time =
original_run_deadline - current_time

Required law:

1. If remaining_run_time is zero or negative:
   - do not spawn a worker;
   - classify the run as RUN_DEADLINE_EXPIRED;
   - stop scheduling;
   - preserve remaining jobs as queued or held;
   - begin governed shutdown.

2. If the job has an authorized job-specific timeout:
   effective_worker_timeout =
   minimum(job-specific timeout, remaining_run_time)

3. If the job has no authorized job-specific timeout:
   effective_worker_timeout =
   remaining_run_time

4. No environment variable, queue field, adapter or worker may increase effective_worker_timeout beyond remaining_run_time.

5. Recovery or restart must reuse the original deadline.

6. A restart, retry or resume must never create a fresh nine-hour window for the same run.

7. Deadline expiry while a worker is active must terminate that worker and its descendants.

8. A deadline-terminated worker must never be marked successful or DONE.

Required worker outcomes:

FAILED
WORKER_TIMEOUT
RUN_DEADLINE_EXPIRED
OUTPUT_OVERFLOW
SPAWN_ERROR
TERMINATED_BY_STOP
UNKNOWN_FAILURE

PHASE 3 — PROCESS-TREE TERMINATION

Extend the current asynchronous worker helper rather than introducing a second worker authority.

Required behavior:

- spawn the worker in a controllable process group or equivalent governed process-tree boundary;
- continue genuine heartbeats while the worker is alive;
- schedule a monotonic timeout against effective_worker_timeout;
- on timeout:
  1. record timeout intent;
  2. send graceful termination;
  3. wait a bounded grace period;
  4. send forced termination if still alive;
  5. verify the child and known descendants are gone;
  6. stop the worker heartbeat interval;
  7. record the exact outcome.

Do not:

- leave a detached orphan;
- mark termination complete based only on sending a signal;
- continue heartbeats after the worker process is gone;
- classify timeout as ordinary failure without recording the timeout cause;
- start another job after the run deadline.

If process-tree termination cannot be proven, return a blocker.

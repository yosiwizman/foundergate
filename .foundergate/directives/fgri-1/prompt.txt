PURPOSE

FounderGate must not require a non-developer founder to monitor a backend terminal.

The current PAES implementation correctly detected a material cost-and-permission decision, but it surfaced that gate through an interactive Terminal question.

That behavior is not acceptable as a FounderGate product workflow.

The permanent product rule is:

A BACKEND WORKER MAY NEVER ASK AN INTERACTIVE TERMINAL QUESTION DURING AN AUTONOMOUS RUN.

When a worker encounters uncertainty or missing authority, it must do exactly one of the following:

1. resolve the issue mechanically from existing disk authority;
2. apply the documented safe default and continue;
3. park only the affected lane, create a structured Founder Decision Inbox request, and continue every unrelated authorized lane.

The Gate Router must sit between all autonomous backend workers and founder authority.

Terminal output is operational evidence.

It is not the founder decision interface.

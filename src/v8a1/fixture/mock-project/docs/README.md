# Luna Café — order ahead

A small website where customers can order coffee and pastries ahead of time and skip the line.

**What it is:** a menu page (Lavender Latte, Butter Croissant, Matcha Cloud) with a practice "Send order" button.
**Status:** demo / preview only — MOCK_ONLY. No real orders, messages, or payments are sent.

Check a public GitHub project

Paste a public GitHub project link and run a real safety check inside a throwaway sandbox. Nothing from the project is installed, built, tested, or run. The only thing done with the code is to byte-compile its Python source — enough to observe that the source parses. The project itself never executes.

    Limitations

    • Source parsing observed (structure parses) — the project's Python source byte-compiles to bytecode. That is not a text search, and the project is never executed. It proves nothing about runtime behavior, dependency correctness, native compilation, integration, safety, or production readiness.

    • Tests not proven
    • Security not proven
    • Production readiness not proven

    If something is missing

    Missing evidence shows UNKNOWN. An old run shows STALE. A different URL is HELD. A private URL is refused. Teardown-pending will not claim "removed." None of these mean success.

    Pause & get help

    You can stop anytime. Nothing here runs project code or touches customer data. If a check is running, pausing requests a stop at the next safe cleanup point — immediate cancellation is not yet proven.

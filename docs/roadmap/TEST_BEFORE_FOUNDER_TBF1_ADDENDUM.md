# Roadmap Addendum — Test Before Founder (TBF-1)

**This is an ADDENDUM.** It does not rewrite the V8.11 constitution; it reconciles with existing
founder-approved governance (`docs/contracts/component-classification.md` evaluation-class control;
`docs/assembly-evidence/FOUNDER_GATE_LEDGER.md` true-gate ledger).

TBF-1 makes **Test Before Founder** a permanent, disk-based, versioned, machine-enforced law binding on
every future lane, CTO task, builder task, checker task, witness package, and merge decision. It is
enforced by `.foundergate/policies/test_before_founder.json` + validators + schemas + selftests +
mutation proofs + exact-SHA CI, and is registered as evaluation-class.

Reconciliation:
- The existing evaluation-class doctrine (D3) governs *how* evaluation-class components change; TBF-1
  is registered under it and follows its oracle-anchored control (independent check + mutation proof +
  green CI + founder signature).
- The Founder Gate Ledger records the founder authorization as a true gate.
- No prior founder-approved gate, acceptance, or doctrine is weakened. TBF-1 adds obligations; it
  removes none.

TBF-1 does not accept Phase 7.1, authorize main merge, adopt OpenSandbox, authorize customer/private
repositories, authorize production, access AKIOR, or contact the M1.

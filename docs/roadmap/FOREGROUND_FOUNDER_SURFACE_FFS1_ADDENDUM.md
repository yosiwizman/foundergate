# Roadmap Addendum — Foreground Founder-Surface (FFS-1)

Addendum extending TBF-1 (does not rewrite it). Amends the active policy to v1.1.0 adding the
`foreground_founder_surface` required class to founder-facing UI work, per the founder authorization,
under the evaluation-class oracle-anchored control (founder signature + independent checker + mutation
proof + exact-SHA CI + updated digest + append-only record). Reconciles with the TBF-1 constitution
and the component-classification doctrine. No prior gate/acceptance is weakened; obligations are added.
Does not authorize a live run, OpenSandbox adoption, main merge, customer/private repos, production,
AKIOR or M1.

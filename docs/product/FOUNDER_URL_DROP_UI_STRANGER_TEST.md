# Founder URL-Drop UI — Stranger Test (Phase 7, Lane B)

A first-time user (a "stranger") must succeed with no coaching. Aligns with the existing FounderGate stranger-test discipline (loopback, MOCK/fixture-only, no live/provider/send/payment path).

## Success criteria (all must hold)
1. Within 30s the stranger identifies **what must not be touched** (private repos, other URLs) from the on-screen warnings.
2. The stranger finds the one primary action without help.
3. The stranger reaches a result that clearly says compileability was observed and build/tests were NOT proven.
4. The stranger never sees a raw localhost:port, terminal command, or developer log presented as something they must act on.
5. The stranger can always find **Pause & get help**.
6. A non-fixture URL is visibly HELD; a private URL is visibly refused.
7. No screen implies the project "works", is "secure", or is "production-ready".

## Fail conditions
Any invented green; any "PASS" without naming what passed; any place the stranger must open a terminal or read a log; any missing-evidence screen that shows green instead of UNKNOWN.

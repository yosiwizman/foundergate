# Why this is convergence, not a third UI

The founder direction is explicit: **do not create a third UI**, and **converge** the live-local
backend behavior into the **proven deck-style Founder operating environment**.

- The prototype's stylesheet is a **copy of the deck's** `fg.css` — same tokens, same `.shell`
  grid, same `.side` / `.card` / `.chip` / `.btn` classes. The only delta is a minimal local
  contrast override so the dark theme meets WCAG AA (this does not change the visual language).
- No new component vocabulary, no new layout system, no alternate theme is introduced.
- The backend behavior attached here is the **same** loopback runner already proven in Founder
  Mode — it is being *moved into* the deck surface, not re-implemented as a competitor.

Result: one product line (deck visual language) gains the real behavior (live-local runner).
That is convergence. The deck remains the canonical UX direction; Founder Mode remains the
temporary live-local proof surface until convergence completes. Neither is discarded.

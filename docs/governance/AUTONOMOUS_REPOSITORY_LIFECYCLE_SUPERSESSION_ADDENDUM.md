# Roadmap Supersession Addendum — ARLC-1

ARLC-1 establishes the permanent Autonomous Repository Lifecycle Law. It
supersedes the "every main merge requires founder approval" rule for
`OPERATIONAL_AUTONOMOUS` actions and formally records that routine mechanically-
qualified repository operations (qualified cumulative merge, superseded-PR
closure, no-loss branch/worktree cleanup, post-merge verification) are backend
Terminal-0 responsibilities. True founder gates (adoption, customer/private
execution, production, release, payments, AKIOR, provider activation, security-
boundary, live runs without standing authority) and all safety-floor/evidence/
checker/Advisor/exact-SHA-CI requirements remain in force. See
`autonomous_repository_lifecycle.json` and the pointer for the machine encoding.

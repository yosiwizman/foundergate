Anti-repeat

Did a caught bug become an automated check that will catch it again? A defect is shown as protected — never again only when a regression check is authored, wired into a suite that actually runs, and proven to reproduce the defect. Anything less is said out loud as not yet protected — can recur; a missing part is never invented. This surface only shows the conversion; it authors, wires, and runs nothing.

Every bug the founder personally catches becomes a new automated check — the system may be wrong, but never wrong the same way twice.

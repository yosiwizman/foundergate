# Final Read-Only Advisor Audit Contract (TBF-1)

Before an acceptance-critical founder witness (UI acceptance and equivalent), a fresh read-only
Solutions Architect independently re-derives the evidence from disk + GitHub and issues a verdict. The
Advisor cannot correct the work it audits. Its presence (evidence manifest `advisor.present`) is
required for UI acceptance readiness. The Advisor treats every builder/Terminal-0 completion report as
a claim until mechanically re-derived.

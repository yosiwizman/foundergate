# AKIOR Safe Scope (for the later gate)
IN SCOPE (only when separately authorized):
- Create ONE new repo under the founder's own AKIOR account.
- Push ONLY a vetted, synthetic-data demo candidate.
- Verify by fresh clone + self-test + clean scans from outside.

OUT OF SCOPE (always):
- Private/customer/production data; credentials; provider keys.
- Provider activation, deployment, billing, spend.
- Outreach, releases, GitHub Pages.
- Any change to the existing task-ledger-demo repo, protected FounderGate main, or PR #200.
- Merges, PR creation, PR-ready marking.

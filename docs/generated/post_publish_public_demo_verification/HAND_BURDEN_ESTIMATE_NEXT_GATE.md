# Founder Hand-Burden Estimate — Next Gate (AKIOR)
- To START AKIOR: one paste of the AKIOR authorization phrase. (~1 paste)
- While running: zero interaction.
- At end: one final ZIP/report back to ChatGPT. (~1 review)
- No terminal commands, no Git, no SHA reconciliation, no raw-log reading required of the founder.
- Prerequisite the founder controls: access to the founder's own AKIOR account (so the new repo can be created there). If AKIOR account access is not ready, the gate simply waits — no burden accrues.

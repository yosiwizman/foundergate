# Final-Head And Metric Guard Standard
Before any run is declared done and its ZIP SHA recorded: (1) make ALL commits including follow-up/hygiene corrections; (2) re-stamp final-head fields to the actual HEAD; (3) re-stamp EVERY metric-bearing report (FINAL_STATUS, FINAL_VERDICT, TEST_REPORT, SCAN_REPORT, PROHIBITED_ACTION_ATTESTATION, verify_summary) so they all agree; (4) run the receipt-consistency guard — must ALL PASS (final-head + metric agreement + zero safety counters + no stale simulation copy). A run may not be "done" while the guard reports any FAIL. This closes both the stale-head class and the stale-metric class.

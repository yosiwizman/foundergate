# Reviewer Package Binding Report
Bound the reviewer console to a REAL sealed-package index (demo/reviewer_console/package-index.mjs) generated by scanning the actual local sealed review ZIPs and recording {name, sha256, bytes}. The reviewer console renders this index read-only (SHA prefix + size per package) and displays an evidence drawer. No fetch/network, no mutation. Tested: package-index.selftest (real index has ≥1 package, valid 64-hex SHA, includes the Max-Wide package) + reviewer read-only guard.

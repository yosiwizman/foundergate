# Founder README — Credential Route Matrix (B7)

**In one sentence:** this is a clear map of the *ways* FounderGate could read a private repo, honestly labeling which one is actually proven (only the throwaway read-only deploy key) and which are still just plans that each need your go-ahead.

**Why it matters:** it stops any future route from quietly borrowing the deploy-key proof's credibility. On the map, the deploy key says "proven with limits"; a fine-grained token, a GitHub App, and an uploaded archive say "planned — blocked"; and touching a *real* repo of yours, or a *customer's* repo, is marked a **true founder gate** that only you can open.

**What to look at:** dashboard → **🧭 Credential Route Matrix** → *Load Credential Route Matrix*. You'll see each route's status, the recommended next step (a fine-grained read-only token proof on the throwaway sandbox), and 20 blocked "bad-idea" attempts. If the data file is missing it shows **UNKNOWN** — never a fake green.

**What it is NOT:** it does not prove any of the planned routes, and it touches no real or customer repo, no provider, and nothing that costs money. Nothing was merged.

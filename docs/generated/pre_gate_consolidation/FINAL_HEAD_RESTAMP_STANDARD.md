# Final-Head Restamp Standard
If any commit is made AFTER FINAL_STATUS/FINAL_VERDICT were written (e.g., a disclosure/doc correction requested by a reviewer), the final-head fields MUST be re-stamped to the new HEAD and the final-head guard re-run. The prior head becomes earlier_frozen_candidate / primary_build. This is the direct fix for the CTO stale-head defect.

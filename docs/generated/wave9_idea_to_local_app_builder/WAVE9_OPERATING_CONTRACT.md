# Lane 0 — Wave 9 Operating Contract
- Wave 9 is a LOCAL-ONLY idea-to-app builder proof: founder idea → guided spec → local app build →
  tests → preview → evidence → founder-readable decision.
- **DISK-ANCHOR (non-negotiable):** every plan, spec, decision, generated app, test, result, evidence,
  refusal, limitation, and next gate is written to disk. No memory-only product decisions.
- No real-world execution: no deploy, billing, provider, real calendar/account/API, customer/private/
  production data, private repo, merge, or PR #200 mutation. No protected gates crossed.
- The generated app is synthetic/local only. Decision never SHIP.
- The founder receives ONE final batch gate.

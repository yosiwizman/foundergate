# FounderGate — Wave 9 Founder Idea-to-Local-App Builder
The pitch-deck promise, first controlled local version: founder idea → guided spec → build plan →
generated local synthetic app (appointment/task planner) → generated tests (PASS 13/13) → local
preview → sealed evidence → founder-readable decision (never SHIP). Includes an Idea Builder UI panel
with a safety classifier that REFUSES/HOLDS unsafe ideas (deploy/calendar/email/charge/prod/merge/
PR#200/security-SaaS). Disk-anchored: every artifact written to disk. Deck-style preserved (fg.css
byte-identical; server-core unchanged). Local-only — NOT production/SaaS/secure/customer/market/paid/
commercial; no real calendar/account/deploy/billing.

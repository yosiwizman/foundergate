# Lane H — Pilot Intake Workflow Spec (no form deployed, no users contacted)
Steps: (1) owner provides a NON-SENSITIVE repo/demo COPY only (public repo, local folder, or demo).
(2) Owner confirms ownership. (3) States objective + which builder was used + scope. (4) Confirms NO
customer/private/production data and NO production credentials. (5) Consents to receive an evidence
report. (6) Excluded actions auto-listed: deploy, billing, real integrations, private data, security
certification. Refusal conditions: private/customer/production data present, or deploy/billing/provider/
account requested → HOLD/REFUSED (separate gate). This is a SPEC; no form is deployed and no user is contacted.

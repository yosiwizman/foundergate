# Lane I — Pricing & Package Hypothesis (every price is a HYPOTHESIS; nothing charged)
| Tier | Price (HYPOTHESIS) | Includes | Excludes |
| --- | --- | --- | --- |
| Free / testimonial exchange | $0 (HYPOTHESIS) | one Safety Check + report, in exchange for honest feedback | no production/security promise |
| Early Safety Check | $99 (HYPOTHESIS) | one check + owner report + evidence ZIP | no repairs, no deploy, no integrations |
| First paid package | $149–$299 (HYPOTHESIS) | check + report + a short written Q&A | no code changes, no live steps |
| Higher-touch report | $499 (HYPOTHESIS) | deeper read + risk narrative + next-steps map | no security certification, no production sign-off |
| Re-check | ~50% of original (HYPOTHESIS) | re-run after repairs | same exclusions |
- What price includes: local evidence + honest verdict + next safe step.
- What price excludes: production readiness, security certification, deployment, billing, real integrations, guarantees.
- When to stop discounting: once a few evaluators say they would pay (Gate 8/9 signal).
- What must be learned BEFORE raising price: do buyers understand it, does it change their decision, would they pay.
No price is validated; nothing is charged; these are hypotheses to test with one evaluator later (Gate 8/9).

# Lane F — Buyer Demo Script (a SCRIPT, not outreach — nothing is sent)
**3-minute flow:**
1. Open the FounderGate dashboard → Safety Check panel. Say: "This checks an AI-built app you own and gives you honest evidence."
2. Open the sample report viewer → Safe sample. Say: "Green = PASS_WITH_LIMITS: the existing tests ran, so continue locally."
3. Risky sample. Say: "Amber = REPAIR: no tests / deps missing, so fix before showing it around."
4. Blocked sample. Say: "Red = REFUSED: it asked to deploy/charge/use real data — we STOP and don't do that without your explicit go-ahead."
5. Point to the evidence packet. Say: "You get a sealed, integrity-checked evidence file — not just an opinion."
6. Point to the disclaimer. Say: "This is honest evidence, not a production guarantee or a security audit."
**Claim-safe language:** "local evidence", "what's proven / not proven", "next safe step", "never ships for you".
**Do-not-say list:** "production-ready", "secure", "SaaS", "customer-ready", "guaranteed", "certified",
"validated", "we deploy it", "we run your private repo" (without a gate), "signed customers", "legal approval".
This is a script for a live conversation; NO email/outreach is created or sent.

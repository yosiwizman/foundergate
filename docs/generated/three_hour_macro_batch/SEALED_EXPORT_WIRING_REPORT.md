# Sealed Export Wiring Report (Subwave 2)
Built a REAL local sealed-package export CLI: `src/evidence_viewer/export-package.mjs`. It reads the real run JSON, assembles a package (EVIDENCE_NOTE.md + RUN_EVIDENCE.json + SHA256SUMS.txt), seals it with `ditto` into a ZIP, and verifies with `unzip -t`; returns the zip path + real SHA-256. Refuses to seal a SHIP decision. Tested: sealed-export.selftest 5/5 (real zip file exists, 64-hex SHA, unzip -t clean, includes note+json+sums). A real exported package is bundled in the master ZIP under exported_packages/.
**Classification: SEALED_EXPORT_LOCAL (real, CLI-backed).** The prior "NOT_WIRED" limitation is retired for the CLI path. The browser Export still downloads a LOCAL_EXPORT JSON (browsers can't spawn ditto); the real sealed ZIP is the CLI tool.

# Founder README — Physical Containment Assurance (plain English)
- FounderGate now has a **model** that tells three very different things apart: software-only isolation (weakest), hardware-assisted containment (stronger), and a physically-cut-off machine (strongest). It **never pretends one is the other.**
- It **refuses** to ever say "unhackable", "escape impossible", or "absolutely secure" — those are permanently blocked.
- It practiced against **32 nasty scenarios** (fake relay states, replayed keys, hidden Wi-Fi, a data-diode turning two-way, power that won't cut) and **caught and held every one** — zero false "all good".
- This is a **model and simulator only.** It did **not** touch any real relay, power, radio, USB, or network, and it does **not** prove real physical security. Real hardware is a separate decision that needs you.
- Real provider / private repo / Gate 8 / deploy / billing / merge all stayed **blocked**. Never SHIP.

# Gate 8 Evaluator Prep Packet — PLANNING ONLY
**This packet does NOT authorize outreach or evaluator contact.** Execution is Gate 8 and requires a separate explicit founder authorization phrase.

- **Who can be a safe evaluator:** one person the founder personally arranges (a trusted operator/advisor). No cold outreach, no list, no customer.
- **What they can see:** the local dashboard + Founder Drive Mode + Reviewer Readiness; the generated synthetic apps and their tests; the crash-test failure/recovery table; sealed evidence ZIPs + checksums; Checker + Terminal Advisor reports.
- **What they cannot see:** any customer/private/production data (there is none), any real accounts/credentials, any deployment or billing (there is none).
- **Exact synthetic-only scope:** everything shown is local + synthetic. No real user data. No network beyond loopback.
- **Hard nos:** no payment, no deployment, no provider spend, no claims of production/SaaS/security readiness.
- **Suggested observation checklist:** Does the founder screen read clearly? Is it obvious what passed vs held? Is it obvious what is blocked? Would the evaluator trust the "never ship" discipline? What is confusing?
- **Stop conditions:** any request to use real data, deploy, bill, or contact anyone → STOP. Any pressure to claim production/customer readiness → STOP.
- **Founder authorization phrase required (example, must be typed by the founder):** "I AUTHORIZE a Gate 8 real-evaluator/buyer feedback session on synthetic/self-owned material, one person I arranged, no customer data."

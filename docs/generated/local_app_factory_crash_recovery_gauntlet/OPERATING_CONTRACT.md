# Operating Contract — Crash / Recovery Gauntlet
- This run tests FAILURE MODES and recovery: broken/corrupted/stale evidence, wrong previews, missing manifests, failing tests, server-unavailable, partial generation, post-checker mutation.
- Local / synthetic only. No network, accounts, calendar, email, customer/private/production data, deploy, billing, provider.
- NOT Gate 8, NOT commercial, NOT production/SaaS/security/customer proof. Decision never "ship".
- Builder cannot certify itself; independent Checker + Terminal Advisor rule.
- Visible/headed browser proof required for UI failure states.
- No PASS/green/preview for broken, stale, mismatched, or unverified artifacts. Recovery only where mechanically safe; original failure always preserved.

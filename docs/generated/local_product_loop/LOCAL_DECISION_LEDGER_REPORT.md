# Local Decision Ledger
Decisions is a local internal ledger. Allowed local statuses only: CONTINUE_DEMO / HOLD / REPAIR /
STOP (recorded as internal notes with no real-world effect). Forbidden statuses (SHIP/MERGE/DEPLOY/
BILL/SEND/CUSTOMER_READY) are not offered and are hard-guarded in code; the real-world action
buttons remain permanently disabled. No decision triggers any real-world action. Verified: safe
statuses recorded; forbidden statuses never recorded; real-world buttons disabled; notice present.

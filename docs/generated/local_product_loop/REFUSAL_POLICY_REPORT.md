# Refusal / Hold Policy
Held or refused (never executed): private repo · customer data · production data · deploy ·
bill/payment · outreach · provider/spend · merge · PR #200 mutation · security/compliance claim ·
arbitrary unknown local path (unless a known safe demo path). Two independent layers: client-side
classification (eligibility gate) and the backend target allowlist. Verified: unsafe objective →
REFUSED; unknown source → REFUSED/HOLD; unsafe path → HOLD; all disable Run.

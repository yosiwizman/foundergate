# Batch Runner
Runs several governed safe local checks in a row (allowlisted self-owned demo targets) and shows a
results table (target, tests, decision never SHIP, status). One real sealed batch evidence export
(the backend's integrity-verified package for the latest run; the table is the founder-facing batch
summary — stated honestly). No provider, no network, no customer data, no private repos, no
deploy/bill/send. Verified: multiple honest rows; export enabled after success; one SEALED export.
Partial/next: independent per-fixture execution of failing/no-test fixtures via a dedicated local
runner is locally buildable next (not claimed as done).

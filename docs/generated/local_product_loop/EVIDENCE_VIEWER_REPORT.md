# Evidence Viewer / Readable Report
The Evidence panel is a founder-safe readable report. After a real export it shows: source checked,
objective, safety classification, tests/result, decision (never SHIP), evidence freshness, export
state (SEALED_EXPORT_LOCAL only when unzip-verified), limitations, and what is NOT proven. No raw
logs, no full SHA, no ZIP internals required from the founder. Verified: receipt includes
source/objective/classification/limitations/not-proven.

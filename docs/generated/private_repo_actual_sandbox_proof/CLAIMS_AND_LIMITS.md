# Claims and Limits (W6) — Actual Private Sandbox Repo Proof
## Allowed claim (evidence passed)
FounderGate created a founder-owned private GitHub sandbox repo and proved **actual private-repo read-only intake** against that repo (exact commit/snapshot binding, secret classification, write-attempt refusal, evidence replay, UI proof, Checker, Gate Advisor).
## Forbidden claims
- NOT customer private repo support complete · NOT private repo support complete · NOT existing valuable repo proven.
- NOT production/SaaS/commercial/paid ready · NOT security/compliance certified · NOT merge-ready · NOT Codex supported · NOT Gate 8 complete.
- NOT least-privilege read-only token proven (existing gh auth is broad: gist, read:org, repo).
- NOT "no secrets possible" · NOT "no risk".
## Standing limits
- ONE founder-owned PRIVATE **sandbox** repo, synthetic contents only. No existing/customer/production repo touched; no credential value exposed; no code executed; no provider called; no write after the seed commit.
- Actual access used **existing broad GitHub auth**, labeled ACTUAL_PRIVATE_SANDBOX_REPO_ACCESS_PROVEN_WITH_EXISTING_GH_AUTH (NOT least-privilege).
- Customer / existing private production repo read-only access remains a separate 🔴 founder gate. Never SHIP.

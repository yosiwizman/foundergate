# Local Authority — No Raw-Boolean Live Authority (Correction 3)
`evaluateAppAction` for create_app/install_app/generate_installation_token ALWAYS returns TRUE_FOUNDER_GATE, regardless of any caller-supplied `live_action_authority` (boolean or truthy string) — the flag is deliberately ignored. `LIVE_ACTION_AUTHORIZED_ELSEWHERE` was removed from the local authority model. `routeStatus()` always reports TRUE_FOUNDER_GATE_GITHUB_APP_LIVE_ACTION_REQUIRED. Proven: `evaluateAppAction({action:'create_app'})` and `evaluateAppAction({action:'create_app',live_action_authority:true})` refuse IDENTICALLY. Live authority must come from a separate mechanically-verified founder-gate object + route that is not built or simulated here.

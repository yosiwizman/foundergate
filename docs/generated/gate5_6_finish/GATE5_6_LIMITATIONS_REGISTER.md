# Gate 5/6 — Limitations Register
1. Launcher: first-run macOS Gatekeeper approval required (not fully hands-free).
2. Scheduled repeatability: template only; not an active system job until the founder loads it.
3. Scope: local internal demo — NOT production, security, compliance, SaaS, customer, or provider-backed.
4. Dashboard assumes the local server is running (launcher starts it; if off, dashboard honestly shows UNKNOWN).
5. Reviewer surface is read-only; deeper multi-surface E2E is a later polish.
6. Acceptance is WITH LIMITS and confers no execution authority for any true founder gate.

# Safe Demo Rule (Lane G)
- Until a unified UI is intentionally designed, demo ONLY the current live-local Founder Mode dashboard for functional proof.
- Use deck screenshots ONLY as context for the broader intended owner workspace, clearly labeled "design concept — mock/display-only."
- Do NOT claim the deck UI is the current live demo unless separately proven with a backend reality matrix.
- Do NOT build more UI skins without a backend reality matrix and founder approval.

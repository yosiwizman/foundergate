# Investor / Founder Confusion Register (Lane F)
| Question | Plain-English answer |
|----------|----------------------|
| Why does the deck UI look different from the demo UI? | They are two surfaces: the deck shows the broader intended workspace as a design concept; the demo is the current, simpler live runner. |
| Which one is real? | The Founder Mode local dashboard is real and runnable today (on your Mac). The deck workspace is a design concept (mock/display-only). |
| Which one has backend? | Founder Mode (real local run-server + sealed export). The deck screens have no backend yet. |
| Are protected files live? | No — "Protected Files" is a design/display concept in the deck, not live enforcement. |
| Is spend control real? | It was proven once, bounded (one real provider call under a $1 ceiling). Not proven at scale. |
| Is this SaaS? | No. There is no hosted service. SaaS is a plan only. |
| Is this production? | No. Everything is local/internal, explicitly not production. |
| Is this customer-ready? | No. No customer data, no customers. |
| Why is the local dashboard simpler? | It is a working slice for the accepted evidence path, made hands-light for a non-developer founder. |
| Is Founder Mode a replacement or a slice? | A slice — the working piece of the broader intended environment, not a replacement for it. |

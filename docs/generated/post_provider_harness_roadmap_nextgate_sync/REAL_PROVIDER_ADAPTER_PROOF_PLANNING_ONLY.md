# Real Provider Adapter Proof — PLANNING ONLY

**THIS DOES NOT AUTHORIZE A REAL PROVIDER CALL.**

- **Purpose:** prove ONE real AI provider runs through the same FounderGate gate that already gates the simulated adapters — real evidence, real (tiny, capped) cost, honest verification — extending the proven Gate 7 pattern to the provider-agnostic contract.
- **Allowed provider choices:** one of Claude (`claude -p`, Gate-7-style) or another the founder names; ONE provider per authorization.
- **Budget cap options:** a hard `--max-budget-usd` cap the founder sets (e.g. $0.50 or $1.00); the run must abort if exceeded.
- **Per-call approval rule:** each real call requires the founder's explicit go-ahead; no unattended loops.
- **No customer data. No private repo. No deploy. No billing. No outreach.** Synthetic/self-owned input only.
- **Stop conditions:** budget exceeded → STOP; any request for customer data/deploy/private repo → STOP; provider overclaim → the gate HOLDs (as with simulated).
- **Evidence required:** exact cost capture, the gate's independent verification (PASS only if artifacts/tests verify), Checker + Terminal Advisor, sealed ZIP.
- **Exact founder authorization phrase required:** "I AUTHORIZE ONE real provider adapter proof, budget cap $X, per-call approval, synthetic/self-owned input only, no customer/private data, no deploy/bill/outreach."

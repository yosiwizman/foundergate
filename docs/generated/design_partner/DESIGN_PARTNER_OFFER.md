# Design-Partner Concierge Safety Check — Offer (draft; no customers claimed)
A hands-on, human-run pilot: you give us a PUBLIC, non-sensitive repo + a small objective; FounderGate runs a governed check locally and returns a plain-English evidence note (what changed, tests, honest ship/do-not-ship/insufficient decision, limitations). Concierge = we operate it; you get the evidence.
- FOR: teams curious about auditable autonomous AI dev on non-sensitive code.
- NOT FOR: anyone needing production deployment, customer/private data handling, security/compliance guarantees — none are offered.

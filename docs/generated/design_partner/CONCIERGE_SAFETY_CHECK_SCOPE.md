# Concierge Safety Check — Scope
IN: one public non-sensitive repo; a small bounded objective; local governed run; sealed evidence note + package.
OUT (will NOT do): private/customer/production repos or data; secrets; deployment; production changes; merges to your repo; security/compliance certification; anything spend-bearing without explicit written cap.
DELIVERABLE: an evidence note (exact SHA, changed files, tests, checker/advisor verdicts, limitations, honest decision) — internal-demo grade, not a production audit.

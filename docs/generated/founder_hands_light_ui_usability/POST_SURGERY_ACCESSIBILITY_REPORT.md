# Post-Surgery Accessibility Report (Lane F)
Practical hand-burden accessibility of Founder Mode:
- Button size: big primary button measured 281x66 px (well above the 44x44 minimum) — easy to click.
- Spacing: fm-actions has 14px gap; buttons are separated.
- Keyboard: buttons are real <button> elements (focusable, Enter/Space activate); reviewer link is a real <a>.
- Contrast: dark-green primary / blue secondary on white — high contrast; dark-mode variants provided.
- Minimal scrolling: the main result (What happened / Can I trust this? / What next?) is in the top Founder Mode panel — no scrolling into technical cards required.
- No tiny required controls; no drag/drop; no mandatory typing — a DEFAULT objective is pre-filled, so Yossi can run with clicks only.
- axe-core: 0 total violations (0 serious/critical).
Result: hand burden minimized; clicking is optional (automation can also run it), typing is optional.

FOUNDERGATE — WHAT THE RESULT MEANS

COMPLETE = the local check finished.
UNKNOWN = not enough evidence, or the local helper is not reachable. Safe, not a failure.
HOLD = do not proceed.
INTERNAL_DEMO_ONLY = a demo result only. It is NOT permission to ship, and NOT production.
Export = saves an evidence package (a sealed record you can keep).

If you ever see UNKNOWN, just re-open with the launcher and click Run again.

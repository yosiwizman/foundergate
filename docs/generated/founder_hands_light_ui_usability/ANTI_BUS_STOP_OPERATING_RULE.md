# Anti-Bus-Stop Operating Rule
- Do NOT create 5-minute micro-runs unless evidence integrity strictly requires it.
- Prefer 45-90 minute safe macro-runs that bundle docs, code changes, checks, screenshots, launchers, and independent reviews together.
- Stop only at true founder gates, visual gates, hard blockers, or failed checks.
- For Yossi, VISUAL gates are legitimate gates.
- Do NOT make Yossi shuttle prompts every few minutes or supervise tool output.
- Do NOT route to evaluator/commercial/paid/SaaS gates before the founder-facing UI is comfortably usable.
This run is an example: one longer batched usability run + one visual confirmation, not many tiny stops.

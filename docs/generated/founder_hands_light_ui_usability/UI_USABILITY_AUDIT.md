# UI Usability Audit (Lane A — honest, pre-improvement)
Audit of the canonical dashboard as a non-developer, post-surgery founder would see it BEFORE this run's changes:
- Main action obvious? Partially — "Start" was one small button among several; not visually dominant.
- Start easy to see? Small button labeled "Start (real local run via server)" — technical wording.
- Export easy to see? Small, disabled button next to Start.
- Too many technical labels? YES — "Exact commit", "Independent Checker", "Gate Advisor", numbered card headings (1-14), monospace values.
- Explains UNKNOWN? Only in prose paragraphs; not next to the result.
- Says local-only/not production/not secure/not SaaS? YES (banner + footer) — good, kept.
- Result tells the founder what to do next? "Next safe action" existed but was buried in a technical card.
- What made it hard for a post-surgery founder? Small buttons; dense technical cards; jargon; the "what do I do" answer not front-and-center; typing an objective looked required.
Conclusion: honest and truthful, but built reviewer-first. This run adds a Founder Mode on top (big buttons, plain English) while keeping the technical view intact.

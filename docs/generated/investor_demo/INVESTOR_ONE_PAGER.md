# FounderGate — Investor One-Pager (internal demo; evidence-backed; NOT production/customer-ready)
**What it is:** an evidence-first *governance layer* for autonomous AI development runs. It lets an AI build/check/review code overnight while proving — from disk, git, and provider logs — exactly what it did, and refusing to over-claim.
**The insight:** the hard part of autonomous AI dev isn't generating code — it's *trusting* it. FounderGate's product is trustworthy autonomy: cost caps, path limits, honest UNKNOWN/STALE states, a founder merge gate, and independent Checker + Gate Advisor on every step.
**What's proven (local, evidence-backed):**
- Autonomous endurance L1→L4 (2h/5h/8h) with duration proven from continuous disk logs, not a wall-clock timer.
- A governed merge into main that only happened on the founder's explicit one-line authorization (never auto).
- Two bounded **real** AI-provider runs under a hard cost cap: a $0.30 witness and a $0.76 real local project — each stayed inside its paths, captured evidence, passed tests, and made a *conservative honest decision* (it would not fabricate a "SHIP").
**What it is NOT (stated plainly):** not production-ready, not customer-ready, not final-beta, not secure/compliant, not deployed, no real customer data, no SaaS. These are honest limits, not omissions.
**Traction:** engineering proof only. No customers, revenue, or design partners yet — none are claimed.
**Ask / next step:** design-partner *concierge* pilots (manual, non-sensitive repos) to validate willingness-to-pay before any product/SaaS build.

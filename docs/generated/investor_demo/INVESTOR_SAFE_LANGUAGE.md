# Investor-Safe Language
USE: "evidence-first governance for autonomous AI dev runs"; "proven guardrails: cost caps, path limits, honest UNKNOWN, founder merge gate"; "internal local demo + real-provider witness ($0.30) + real local project ($0.76), all under controls"; "not yet production/customer-ready — by design, on purpose, honestly".
AVOID: "production", "customer-ready", "secure/compliant", "deployed", "SaaS", "guaranteed", "we have customers/revenue", "ships production software".
FRAME: the moat is *trustworthy autonomy* — it proves what it did and refuses to over-claim — not raw code generation.

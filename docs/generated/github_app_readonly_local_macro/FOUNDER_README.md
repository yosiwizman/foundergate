# Founder README — GitHub App Route (local preparation)

**In one sentence:** FounderGate built and tested all the *safe scaffolding* for the next credential route — a GitHub App that could read your private repo — but it did **not** create or install any real app, because that's a live action only you can authorize.

**What it built:** the rules that force every live step (create app, install app, make a token) to stop and ask you; a guard that refuses to let any key or token leak; a clearly-fake practice token that can never be mistaken for the real thing; a checklist a real proof would have to pass; 34 "bad-idea" attempts all refused; and an honest screen that shows "local only — not proven."

**What it did NOT do:** no real GitHub App, no installation, no token, no repo read, no other repos, no provider, nothing merged.

**Your next decision (a true founder gate):** if you want the real GitHub App proof, you'd authorize FounderGate — with a separate signature — to create ONE temporary app, install it on **only** the sandbox repo (read-only), make a short-lived token, prove the read, then uninstall it. Until you do, this route stays "prepared, not proven."

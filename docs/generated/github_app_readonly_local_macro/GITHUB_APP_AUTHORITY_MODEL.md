# GitHub App Authority Model (W1)
Local model of the GitHub App read-only route. **Every live action is gated:** create-app / install-app / generate-installation-token → `TRUE_FOUNDER_GATE` unless a separate founder signature sets `live_action_authority`. Scope rules (13/13 tests): all-repos / multi-repo install → HOLD_SCOPE_UNSAFE; write/admin/workflow/issue/PR/secret/deployment permission → the matching HOLD; non-sandbox target → HOLD_TARGET_NOT_SANDBOX. Only **single sandbox repo + Contents:read + Metadata:read** is an `ACCEPTED_READONLY_SPEC`. Route is **never "proven"** by this local macro; `private_key_seen=false`, `installation_token_seen=false`.

# Founder Witness UI Review Packet
A package for the founder to visually review the local UI LATER — without reading code, logs, or ZIP internals. This is NOT founder approval, NOT final beta acceptance, NOT a product launch, NOT a security review.
## How to review (when you choose)
1. Double-click launch-foundergate.command (a one-time macOS trust prompt may appear — that's the OS, not FounderGate).
2. The dashboard opens in your browser. Type an objective, click Start; watch a real local run appear (a real commit, real test counts, an honest INTERNAL_DEMO_ONLY decision).
3. Click Export; a real sealed evidence package is created and verified.
4. Open the reviewer console; open a package drawer; see the SHA-256 + file manifest, read-only.
## What this proves to your eyes
That the local UI truthfully shows real runs and real evidence, operated without a terminal. Nothing more.

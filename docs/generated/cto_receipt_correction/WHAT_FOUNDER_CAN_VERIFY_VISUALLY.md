# What The Founder Can Verify Visually
- That double-clicking the launcher opens the dashboard (no terminal typing).
- That Start shows a real commit + real test counts + an honest INTERNAL_DEMO_ONLY decision (never SHIP).
- That Export produces a real sealed package the reviewer can open read-only.
- That the founder never had to use a terminal, read a log, or reconcile a SHA.
That is the ENTIRE scope of visual verification.

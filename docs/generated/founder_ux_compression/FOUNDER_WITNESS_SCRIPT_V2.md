# Founder Witness Script v2 (~3 min, plain English)
1. Double-click the launcher. Your browser opens the dashboard. (macOS may ask you to allow it once — that's normal.)
2. Type a short goal (e.g., "add a check and prove tests pass"). Click **Start**. In a moment you'll see: a code version, tests passing, and a decision that says **INTERNAL_DEMO_ONLY** — it never says "ship".
3. Click **Export**. It makes a sealed evidence file you can keep.
4. Open the **Decision Room** tab. It recommends your next step (publish the demo) and lists every option with plain-English pros/cons — but nothing on that page acts.
5. Open the **Reviewer** tab. The top box explains, in plain English, that these are honest sealed records. You don't need to read the technical list.
That's it. You just watched a real local check and a real sealed record — with no terminal, no code, no risk. This is an internal demo, not a product; it's not secure, not production, and it did not touch anything private or paid.

# Founder Witness — One-Page Guide
- **Start** = run a real check on a safe demo project. **Export** = save a sealed record. **Decision** = never "ship" (INTERNAL_DEMO_ONLY).
- **Decision Room** = your options + a recommendation (publish the demo first). No buttons act.
- **Reviewer** = proof the work is recorded (checksums). Founder box up top explains it.
- **You cannot break anything** — it's local, review-only, no network to the outside.
- **Nothing here means** production, secure, compliant, SaaS, customers, revenue, or approval.
- **Next step (later, your call):** publish the demo repo with the phrase in the Decision Room.

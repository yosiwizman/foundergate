# Why Publish Demo First (or not)
FOR: lowest-risk external step; the candidate is clean, self-owned, non-sensitive, 30/30, MIT-licensed; gives you a concrete artifact to show an investor or first contact; nothing private/paid/production is touched.
AGAINST / caveats: publishing is public and semi-permanent — do it under YOUR OWN account, as a NEW repo, and never claim production/secure/customer. It proves clean honest code exists, not demand.
Net: recommended first — but it is still a gate only you cross, with the exact phrase, in a separate step.

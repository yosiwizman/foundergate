# Launcher (no-terminal start)
`~/Desktop/FounderGate_Start_Here/Open_FounderGate_Converged_Demo.command`: reuses or starts the
local server, waits for `/api/health`, then opens the converged demo. No terminal interaction, no
command-line instructions. `README_FIRST.txt` covers the one-time macOS "Open" step in plain
English. Plain-English help files:
README_FIRST · WHAT_TO_CLICK_CONVERGED_DEMO · WHAT_REPO_CAN_I_USE · WHAT_OBJECTIVE_CAN_I_USE ·
WHAT_IS_LIVE_VS_DISPLAY_ONLY · WHAT_TO_DO_IF_UNKNOWN · WHAT_TO_DO_IF_HOLD · WHAT_TO_DO_IF_EXPORT_FAILS ·
WHAT_NOT_TO_DO.

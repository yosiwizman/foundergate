# Pilot Intake Rules (preparation)
Before any hypothetical pilot session (none run here):
1. Input MUST be self-owned or synthetic. No customer/private/production data — refuse and stop if offered.
2. No credentials, tokens, secrets, or environment dumps enter the session.
3. No deployment, billing, payment, or account-linking actions.
4. No security/compliance/production/commercial claims are made verbally or in writing.
5. Evidence shared is only sealed, token-scanned packages; reviewer mode is read-only.
6. If the evaluator requests anything on the forbidden list, the session pauses and the request becomes a separate founder decision.
7. No prospect list is built; no one is contacted as part of preparation.

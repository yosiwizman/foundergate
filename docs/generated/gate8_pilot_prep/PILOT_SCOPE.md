# Commercial Pilot — Scope (PREPARATION ONLY, not launched)
This defines a HYPOTHETICAL founder-controlled pilot. It is planning only; no pilot is run, no one is contacted, no data is collected.

## What the pilot WOULD offer (bounded to accepted evidence)
- FounderGate as an evidence-first governance layer for a single, self-owned, non-sensitive demo repository.
- Deliverable per run: a sealed, hash-locked evidence package (tests + independent Checker + Gate Advisor + honest decision that never says SHIP).
- The no-terminal operator dashboard (Gate 5, accepted with limits) + repeatability discipline (Gate 6) + a bounded cost-controlled provider check (Gate 7).

## Explicitly OUT of pilot scope
- No customer/private/production data. No deployment/hosting. No billing/payments. No SaaS. No multi-tenant. No security/compliance guarantee. No outreach.
- No public/customer beta. No provider use at scale. No claims of production or commercial readiness.

## Pilot shape (hypothesis)
- Format: a founder-run, screen-shared or local walkthrough on a synthetic/self-owned repo.
- Duration: a single bounded session; no ongoing service commitment.
- Success signal (for the founder only): did an evaluator find the honest, hash-locked evidence trail credible and useful? Qualitative only — NOT paid-demand validation.

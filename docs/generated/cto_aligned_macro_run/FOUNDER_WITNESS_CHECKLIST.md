# Founder Witness Checklist
- [ ] Double-click launcher; dashboard opens (no terminal typing).
- [ ] Type an objective; click Start; see a real commit + real tests + INTERNAL_DEMO_ONLY.
- [ ] Click Export; see SEALED_EXPORT_LOCAL (real ZIP).
- [ ] Open reviewer console; open a package drawer; see SHA-256 + manifest.
- [ ] Confirm you never had to open a terminal, read a log, or reconcile a SHA.
Witnessing is not approval; final beta acceptance remains a separate founder gate.

# Developer / Reviewer Mode — Requirements
Full technical detail for an independent reviewer.
- Exact commit SHAs, branch names, base/head, tree hashes.
- Changed-file lists and diffs.
- Test logs and self-test output.
- Evidence paths, SHA256SUMS, freeze manifests + root hashes.
- Checker + Gate Advisor full reports and the guard outputs (final-head, receipt-consistency).
- Invariant checks (protected main, PR #200, public repo heads).
- Everything needed to independently reproduce and audit a run.

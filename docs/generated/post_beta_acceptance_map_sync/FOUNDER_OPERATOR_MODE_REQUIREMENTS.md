# Founder / Operator Mode — Requirements
Plain English, action-focused, NO raw logs, NO SHAs, NO diffs.
- One screen: current run status (Running / Blocked-needs-you / Done).
- Big chips: Evidence = Fresh/Stale/Unknown · Tests = 30/30 · Checker = Clean · Gate Advisor = Ready/Hold.
- "What this proves" and "What this does NOT prove" panels in plain language.
- Actions: Start recommended next run · Stop · Download evidence ZIP.
- When blocked: one plain sentence saying exactly what the founder must do (e.g. "authorize the next gate with this phrase").
- Never shows: terminal, logs, commit hashes, file paths, branch names.

# Real-Evaluator Pilot — Refusal Rules
During any future real-evaluator session, REFUSE and stop if:
- any customer/private/production/real data is offered or requested;
- a deployment, billing, payment, or account-linking is requested;
- a security/compliance/production/commercial claim is expected;
- the evaluator asks to run FounderGate on their own repo (separate gate);
- outreach to further people is implied.
Each refusal converts the request into a separate, explicit founder decision.

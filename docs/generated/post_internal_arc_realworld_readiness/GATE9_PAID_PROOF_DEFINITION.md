# Gate 9 — Paid-Proof Definition (planning only; NOT authorized)
Defines what would later count as "paid proof". No billing, no Stripe, no payment link, no invoice, no price quote, no outreach is done here.
Paid proof = a real, willing party voluntarily pays a real (non-trivial, non-refunded-as-favor) amount for a FounderGate deliverable, recorded honestly, with the payer's informed understanding of the INTERNAL_DEMO_ONLY limits.

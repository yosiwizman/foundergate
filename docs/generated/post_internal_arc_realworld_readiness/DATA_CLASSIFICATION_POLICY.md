# Data Classification Policy (planning)
- Class 0 (today): synthetic/self-owned demo — the ONLY data allowed now.
- Class 1+ (future, gated): customer/private/production data — requires a real security/compliance build, DPA, and explicit gates. Not permitted today.
Policy: no Class 1+ data touches FounderGate until Gate 10 security/compliance work is separately authorized and built.

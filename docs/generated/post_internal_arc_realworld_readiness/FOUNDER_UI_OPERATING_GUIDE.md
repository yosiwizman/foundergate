# Founder UI Operating Guide (for Yossi, no ChatGPT/Claude needed)
Safe for synthetic/self-owned INTERNAL use only.
1. Double-click the launcher (tools/launcher/foundergate-local-dashboard.command). First time on a Mac you may need to right-click -> Open once (macOS security). It starts a local server and opens the dashboard.
2. In the dashboard, type a short objective and click Start. Wait for COMPLETE. You'll see tests (e.g., 30/30), a decision (it never says "ship"), and an evidence-freshness chip.
3. Click Export to create a sealed evidence file. If a step's info isn't available, the page shows UNKNOWN — that's honest, not a bug.
You never need a terminal, never read logs, never read code or long ID numbers, and never copy text between tools.
Stop and do NOT use this on customer/private/production data — that's a separate decision.

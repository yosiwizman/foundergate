# Real-Evaluator Pilot — Risk Register
| # | Risk | Mitigation |
|---|------|-----------|
| 1 | Evaluator brings real/customer data | Refusal rules: refuse any non-synthetic input; stop the session |
| 2 | Over-reads demo as production-ready | Frame + close statements pin INTERNAL_DEMO_ONLY; claims matrix enforced |
| 3 | Slides into a sales/pricing conversation | No price/offer; pricing is hypothesis; that's a separate gate |
| 4 | Evaluator asks to run on their repo | Politely defer — that's a separate true founder gate, not authorized |
| 5 | Accidental outreach/commitment | No scheduling/commitment made during preparation; founder controls contact |
| 6 | Data/credential exposure | Self-owned demo only; sealed exports are token-scanned |

# Common Failures And Holds (plain English)
- "UNKNOWN" chips: the info isn't available (e.g., the local server isn't running). Honest, not broken — re-launch via the launcher.
- Export disabled/unavailable: there's no completed run to export yet — click Start first.
- Gatekeeper warning on first launch: right-click the launcher -> Open once (a one-time macOS security step).
- If the dashboard ever showed a green result without a completed run, that would be wrong — by design it can't; it shows UNKNOWN instead.
The system is built to say UNKNOWN/HOLD rather than fake a result. A HOLD is safe.

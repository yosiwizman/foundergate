# Real-Evaluator Pilot — Gate Packet (PREPARATION ONLY; not authorized)
Defines the next true founder gate: a pilot where a REAL person (not the founder) watches/evaluates. Planning only — no contact, no scheduling, no prospect list, no data.
## Variants (all synthetic/self-owned; none authorized here)
1. Real evaluator WATCHES the synthetic/self-owned demo only (no hands-on, no data).
2. Real evaluator gives FEEDBACK only; brings NO data of their own.
3. Real evaluator later requests use on THEIR repo — a SEPARATE later gate (not authorized; would involve third-party data/access).
## Preconditions before this gate could be authorized
- Founder identifies (privately) a willing evaluator — FounderGate does not build a prospect list or contact anyone.
- Synthetic/self-owned demo only; refusal rules (below) in force.
## What it would prove / not prove
- Would add: a real outside person's qualitative reaction to the honest evidence flow.
- Would NOT add: paid demand, market validation, production/security/SaaS readiness.

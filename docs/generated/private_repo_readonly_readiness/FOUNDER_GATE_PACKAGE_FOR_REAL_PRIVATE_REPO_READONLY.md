# Founder Gate Package — Real Private Repo Read-Only Access (decision preparation)
> This PREPARES a future decision. It is NOT a signature and authorizes nothing by itself.

1. **What would be authorized:** read-only metadata/archive access to **ONE exact private GitHub repository** at an exact commit.
2. **What credential would be required:** a fine-grained GitHub token (or GitHub App) with **read-only Contents** on that one repo, stored locally only (Keychain loader, git-ignored). Never pasted into chat or committed.
3. **What would NOT be authorized:** write access · code execution · build/test · deploy · billing · customer data · protected-main merge · PR changes · provider calls.
4. **What remains unproven:** customer repo support · private repo support complete · production readiness · SaaS readiness · security certification.
5. **Undo / reversibility:** revoke the token or uninstall the GitHub App; delete the local snapshot + evidence copy. Fully reversible.
6. **Evidence recommendation:** proceed only after this readiness package is clean (it is: 25/25 refusals, replay verified, Checker + Gate Advisor) AND the founder chooses the exact private repo + read-only credential route, then gives an explicit founder phrase.

# Authority Model — Private Repo (W1)
Six proof levels, NEVER equivalent:
1. **Public repo proof** — no real private access; no founder phrase.
2. **Private repo readiness proof (synthetic)** — this run. MUST NOT claim actual private repo access.
3. **Actual private repo read-only proof** — requires: exact repo identifier · exact credential source · exact scope · founder phrase · no code execution · no writes · no merge · no deploy. 🔴 blocked (founder gate).
4. **Private repo execution proof** — 🔴 blocked.
5. **Private repo write proof** — 🔴 blocked.
6. **Customer data proof** — 🔴 blocked.
Readiness (2) does NOT authorize or imply (3)+. `classifyProof` refuses inflation and any real-access level without an explicit founder phrase + all requirements.

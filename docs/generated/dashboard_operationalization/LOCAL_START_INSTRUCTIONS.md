# Local Start Instructions (founder-friendly)
1. In a terminal-free way, an operator serves the folder: `cd demo/founder_operator_dashboard && python3 -m http.server 4860` then open `http://127.0.0.1:4860/index.html`.
2. Pick a target, type a plain objective, press **Start** — you'll see a deterministic simulated run (status, commit, tests, Checker, Advisor, honest decision).
3. Press **Export** to download a local JSON summary.
4. Press **Stop/pause** anytime. Nothing deploys, spends, or contacts anyone.
(Serving the folder is the one command an operator runs; the founder only clicks.)

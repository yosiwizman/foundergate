# Facilitator Script (founder runs this; language pinned to the claims matrix)
Open (say verbatim): "This is an INTERNAL DEMO on a self-owned, synthetic repo. It is not production, not secure, not a hosted product, and it never says 'ship'. I'd like your honest reaction — no data of yours, no signup, no payment."
Show:
1. Run the self-owned demo self-test (30/30) from a clean state.
2. Open the local dashboard; click Start -> live 30/30, decision INTERNAL_DEMO_ONLY (never SHIP), FRESH.
3. Click Export -> a real sealed evidence file (tamper-evident checksum).
4. Show the independent Checker + Gate Advisor separation on a prior sealed receipt (read-only).
Ask the evaluator (feedback only): "Is the sealed, honest evidence trail credible? Is the no-terminal flow understandable? What would you want before trusting it on real work?"
Close (say verbatim): "This proves engineering-discipline and a tamper-evident trail on synthetic material — not production, security, compliance, customers, or commercial readiness."
REFUSAL RULES (live): if the evaluator offers real/customer/private data, asks to run it on THEIR repo, requests deployment/billing/payment/account-linking, or expects a security/compliance/commercial claim — STOP; that becomes a separate founder decision. Do NOT quote a price, offer signup, collect data, or promise timelines.

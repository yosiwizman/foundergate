# How To Complete The Real-Evaluator Session
1. Founder shows the demo to the privately-arranged real evaluator (in person or screen-share) using kit/FACILITATOR_SCRIPT.md. The demo is already captured (kit/WHAT_THE_EVALUATOR_SEES.md) — you can replay or re-run it live.
2. The founder records the evaluator's ACTUAL words into kit/EVALUATOR_FEEDBACK_CAPTURE_TEMPLATE.md (or simply relays them to ChatGPT).
3. Enforce the refusal rules live: no real data, no their-repo run, no billing/payment/deployment/account-linking, no security/compliance/commercial claims.
4. Bring the real feedback back. Then a genuine real-evaluator session record can be sealed with an independent Checker + Gate Advisor.
Do NOT let anyone (including ChatGPT) invent the evaluator's reaction. Only real feedback counts.

# Longer Gate-to-Gate Workflow Rule
- Do NOT create micro-HOLD records unless evidence integrity strictly requires it.
- Bundle safe work into longer runs; stop only at true founder gates, visual gates, or hard blockers.
- For Yossi, a VISUAL GATE counts as a legitimate gate.
- Do NOT treat an automated witness as founder-lived experience.
- Do NOT advance commercial/evaluator/paid/SaaS gates before the founder can actually see and use the UI.
- Prefer one longer run + one visual confirmation over many tiny 5-minute bus stops.

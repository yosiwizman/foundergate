# What the Client Receives
- A **plain-English evidence note**: exact commit SHA, changed files, tests run + results, duration (from disk logs), cost (if any).
- **Independent Checker + separate Gate Advisor verdicts** (read-only reviews).
- An **honest decision**: INTERNAL_DEMO_ONLY or SUITABLE_FOR_CONCIERGE_TRIAL_WITH_LIMITS (never SHIP).
- A clear **limitations** section.
- A **20-minute walkthrough** of the note.
- Optionally, a **sealed local package** (checksummed) they can keep.

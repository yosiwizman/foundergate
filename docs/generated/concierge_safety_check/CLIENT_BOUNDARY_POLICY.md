# Client Boundary Policy
What the concierge Safety Check **does**: runs a governed, bounded change locally on a public non-sensitive repo and returns an honest evidence note.

What it **explicitly does NOT do** (state this to every prospect):
- No production deployment.
- No merge into the client's repository.
- No security certification, no compliance certification, no audit sign-off.
- No production-readiness claim.
- No handling of private/customer/production data or secrets.
- No unattended, at-scale, or arbitrary-repo support.
- No guarantee of revenue, outcomes, or fitness for a particular purpose.

The deliverable is **internal-demo grade**: proof that governance and honesty work on a bounded local run — not a production audit. Set this expectation before the run, not after.

# Qualification Checklist (tick before running)
- [ ] Prospect identified (real person, not invented).
- [ ] Public, non-sensitive repo available.
- [ ] Secret scan clean (no real tokens/keys).
- [ ] No customer/private/production data in the repo.
- [ ] Objective is small and bounded (one sentence).
- [ ] Paths-to-avoid noted.
- [ ] Prospect accepts honest do-not-ship / insufficient outcome.
- [ ] Run type chosen: no-provider rehearsal OR founder-authorized bounded real run (cap $___).
- [ ] Note recipient confirmed.
- [ ] Time window agreed.

All boxes ticked → proceed. Any unticked box that can't be resolved → decline or defer.

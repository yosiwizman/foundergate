# Forbidden Claims (hard — never say or imply)
production-ready · customer-ready · final beta · secure · compliant · certified · audited · deployed · SaaS ready · arbitrary-repo support · customer-data-safe · investor-guaranteed · revenue-guaranteed · "merge = shipped" · "we have customers / design partners / revenue" · validated willingness-to-pay · "it works on your private/production repo" · "your data is certified safe" · any security or compliance guarantee.

If a deliverable contains any of these, it must be corrected before use.

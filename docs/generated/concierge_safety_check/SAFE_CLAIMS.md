# Safe Claims (concierge phase — what you MAY say)
- "FounderGate runs a governed, bounded code change locally and returns an auditable evidence note (exact commit, tests, honest decision, cost cap)."
- "It refuses to fabricate a 'ship' — an honest do-not-ship / insufficient is a valid outcome."
- "It ran autonomous endurance proofs (2h/5h/8h) with duration proven from disk logs, and two tiny bounded real-provider runs under a hard cost cap — as internal, local demos."
- "It merges only behind an explicit founder gate; it never merges or ships without the founder's word."
- "This concierge Safety Check is an early internal demo on public, non-sensitive repos only; nothing leaves your machine except the evidence note."
- "Pricing is an open hypothesis — the first run is free and I want honest feedback."

Say plainly: "We proved the governance and honesty work, cheaply and safely, on local demos. We have NOT proven production/customer readiness, and we won't claim it."

# Free vs Paid First Run — Decision

**Recommendation: make the first run FREE.**

Why:
- The first run's job is **learning + trust + a reference**, not revenue.
- Charging before you've proven the note is useful to a real human risks a "no" that kills momentum.
- A free run lowers the bar to "yes" and gets you real feedback fast.

**When to introduce price (hypothesis):** only after ≥1 free run where the prospect says the note was genuinely useful. Then float H2/H3 as questions, not quotes.

**Guardrail:** "free" still means capped — if a run needs real provider spend, that's the operator's small, capped cost, disclosed. Never imply the free run has hidden costs to the prospect.

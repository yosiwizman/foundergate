# Founder Low-Hand Runbook

> For Yossi (non-developer, post-hand-surgery). You do NOT type shell commands, read raw logs, or reconcile SHAs. Your job is decisions and conversations.

**Your four moves, in order:**
1. **Pick a target.** One public, non-sensitive repo you (or a friendly contact) own or are happy to use. That's it — a URL.
2. **Say the objective in one sentence.** e.g. "Add input validation to the CLI and prove the tests still pass."
3. **Authorize the run type.** Either "no-provider rehearsal" (free, deterministic) or "bounded real run, cap $5" (you say the number). Never feel pressured past a cap.
4. **Show the evidence note.** Read the plain-English note to the contact. Ask the one honest question: "would this be worth paying for eventually?"

**You never have to:** operate git, read logs, fix bugs, or confirm checkpoints. The operator/assistant runs everything gate-to-gate and hands you a finished note.

**You only get pulled in for:** a real spend authorization, a real outbound contact, a true forbidden boundary, or the final package. Nothing routine.

**Hand-safe rule:** if a step would need you to type more than a URL, one sentence, and a yes/no — that's a signal the operator should absorb it, not you.

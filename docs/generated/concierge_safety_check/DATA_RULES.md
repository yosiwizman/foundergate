# Data Rules (hard)
- **Public, non-sensitive repositories ONLY.** No secrets, credentials, tokens, customer/private/production data — ever, during the concierge phase.
- **Nothing leaves the local machine** except the evidence note we hand you. No external sends, no third-party analytics, no telemetry.
- **If a repo contains anything sensitive, we STOP and decline.** No exceptions during the concierge phase.
- **No data retention beyond the run package.** The sealed run package stays local; the prospect receives the plain-English note.
- **No credentials are ever requested or stored.** No key enrollment, no auth handoff.

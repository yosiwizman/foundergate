# Stop Rules (concierge phase)

STOP immediately, package honestly, and tell the prospect the truth if any of these appear:
- The repo turns out to be private, or contains secrets / credentials / tokens / customer / private / production data.
- The objective would require deployment, a merge into the client repo, or a production change.
- The objective would require handling sensitive data or a security/compliance guarantee.
- A real provider spend beyond the founder-authorized cap would be needed.
- Any outbound contact, external send, or third-party action would be needed to complete the run.
- The evidence contradicts a claim you were about to make (evidence contradiction).
- A forbidden claim cannot be removed from a deliverable.
- The independent Checker returns unresolved FINDINGS, or the Gate Advisor says HOLD.
- Any hard blocker (tooling, disk, corruption).

**On stop:** never fabricate a PASS/SHIP to finish. Deliver an honest "insufficient evidence" or "declined — out of scope" note. An honest stop is a successful concierge outcome, not a failure.

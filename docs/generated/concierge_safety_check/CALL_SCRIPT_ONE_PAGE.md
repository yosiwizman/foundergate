# Call Script — One Page

**Open (honest frame):**
"Thanks for the time. Quick frame: this is an early internal demo. I'm testing whether *governed, auditable autonomy* is useful to you — I'm not selling a finished product."

**The idea (15 sec):**
"You give me one public, non-sensitive repo and a small objective. FounderGate makes the bounded change locally and I hand you an evidence note — exact commit, tests, an honest ship / do-not-ship / insufficient decision, under a hard cost cap. Nothing leaves your machine except that note."

**Show:** the sample evidence note (SAMPLE_EVIDENCE_NOTE / the demo site's Sample Report page).

**Be explicit about limits:**
"Not production-ready, not a security or compliance certification, public repos only, honest do-not-ship is a fine outcome."

**The one ask:**
"Would a governed evidence note like this be worth paying for eventually — and what would make it a clear yes?"  (Then listen. Don't claim it already is.)

**Close:** "If you're up for it, pick a low-stakes public repo and I'll run it free."

# Pilot Offer Options (structures to test — no pricing validated)

**Option A — Free first run (recommended to start).** One free concierge Safety Check on a public non-sensitive repo, in exchange for honest feedback and (if they're happy) a reference. Goal: learn + earn trust. No money changes hands.

**Option B — Free run, then paid follow-ups (hypothesis).** First run free; subsequent governed evidence notes at a hypothetical flat rate. Tests whether the note has repeat value.

**Option C — Small paid pilot (hypothesis).** A hypothetical low flat fee for a bounded set of runs over a short window. Only worth proposing AFTER a free run lands well.

**All options during the concierge phase:**
- Public, non-sensitive repos only.
- Deliverable = evidence note (internal-demo grade).
- No deployment, no security/compliance certification, no production claim.
- Any real-provider spend is capped and disclosed.

Start with **Option A**. Do not lead with price. The first job is signal, not revenue.

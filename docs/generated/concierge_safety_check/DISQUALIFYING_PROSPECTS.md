# Disqualifying Prospects (decline these, politely)
Decline (for the concierge phase) if the prospect:
- Only has **private / customer / production** repos to offer.
- Wants a **production deployment**, a merge into their repo, or a live change.
- Needs a **security or compliance certification / audit sign-off.**
- Expects a **finished, supported SaaS** today.
- Cannot tolerate an honest **do-not-ship / insufficient** outcome.
- Wants you to handle **secrets, credentials, or sensitive data.**
- Pushes for **unattended, at-scale, or arbitrary-repo** runs.

Declining protects both sides and keeps every claim truthful. A polite decline: "That's exactly the kind of thing FounderGate isn't ready for yet — I only run this on public, non-sensitive repos as an early demo. I'd rather be honest than overpromise."

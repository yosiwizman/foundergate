# Success Metrics (concierge phase — learning, not revenue)
Primary (what a good outcome looks like):
- **1 real prospect** agrees to a run on a public non-sensitive repo.
- **1 evidence note delivered** and walked through.
- **Honest verbal signal** captured: is a governed evidence note useful? Worth paying for eventually? What would make it a yes?

Secondary:
- A **reference / testimonial willingness** (only if genuinely offered).
- **Repeat interest** (would they want another run?).
- **Objection patterns** logged (what scares or excites people).

**Explicitly NOT success metrics yet:** revenue, number of customers, ARR, conversion rate. Claiming any of those now would be false. The metric that matters first is *honest signal from one real human*.

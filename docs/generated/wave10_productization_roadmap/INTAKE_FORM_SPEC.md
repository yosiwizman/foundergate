# Lane J — Intake Form Spec (no real form deployment)
Fields:
- Founder name / project name.
- Repo / folder / demo source (public repo URL, or a local folder path, or a demo).
- **Ownership confirmation** (checkbox: "I own this material").
- Objective (what they want checked).
- What they want checked (tests / structure / evidence).
- **Does customer/private/production data exist?** (if yes → HOLD; not accepted without a separate gate).
- **Is deploy/billing/provider/calendar/account requested?** (if yes → REFUSED here; separate gate).
- **Authorization checkbox** ("I authorize a read-only local Safety Check on self-owned material").
- Excluded items (auto-listed: deploy, billing, real integrations, private data, security certification).
- Evidence delivery consent.
- Required refusal conditions (private/customer/production data, deploy/billing/provider/account requests, non-owned material).
This is a SPEC. No form is deployed or hosted.

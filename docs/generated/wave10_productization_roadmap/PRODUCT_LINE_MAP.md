# Lane B — Product Line Map
For each: customer · input · output · proof today · built · not built · must-not-claim · pilot price HYPOTHESIS · required next proof · founder gate before selling.

## Product 1 — FounderGate Safety Check
- Customer: non-dev founders / small teams who built an app with AI tools and want a sanity check.
- Input: a self-owned public repo, a local folder, or a demo (no private/customer/production data).
- Output: a founder-readable evidence report (PASS/HOLD/REFUSED/REPAIR) with what is/ isn't proven.
- Proof today: repo + folder proofs on self-owned material; sealed evidence; refusal recording.
- Built: read-only clone/inspect, classify, run existing tests (no install), sealed evidence.
- Not built: security certification, production readiness, private-repo-at-scale, real integrations.
- Must NOT claim: production/secure/SaaS/customer/commercial readiness or paid/market validation.
- Pilot price HYPOTHESIS: $150–$500 per check (to be validated; not yet charged).
- Required next proof: one real buyer feedback (Gate 8) + one paid proof (Gate 9).
- Founder gate before selling: accept roadmap + authorize a Safety Check sample report + Gate 8.

## Product 2 — FounderGate Guided Local MVP Build
- Customer: founders wanting a small local prototype built with evidence.
- Input: a plain idea (synthetic/local scope). Output: a local synthetic app + tests + evidence.
- Proof today: Wave 9 (appointment/task planner, 13/13). Built: idea→spec→app→tests→preview→evidence.
- Not built: production delivery, hosting, real data, real integrations.
- Must NOT claim: production app delivery or commercial readiness.
- Pilot price HYPOTHESIS: $500–$2,000 per local prototype (to be validated).
- Required next proof: real buyer feedback; scope guardrails. Gate before selling: Gate 8.

## Product 3 — FounderGate Live Readiness Review
- Customer: founders about to go live who want a risk map. Input: their evidence + intended live steps.
- Output: a readiness report (what must be gated before deploy/billing/integration).
- Proof today: Live Edge Readiness planning packet. Not built: the actual live systems.
- Must NOT claim: a security certification or that the product is deploy-ready.
- Pilot price HYPOTHESIS: $300–$1,000. Next proof: Gate 8. Gate before selling: Gate 8.

## Product 4 — FounderGate Evidence Report / Investor Diligence
- Customer: investors/advisors/agencies vetting an AI-built app. Input: a self-owned repo/folder/demo.
- Output: an evidence index + claim-blocker + false-green check + honest proven/not-proven summary.
- Proof today: evidence export/replay/compare; claim-blocker; sealed ZIPs.
- Must NOT claim: audit certification or market validation.
- Pilot price HYPOTHESIS: $500–$3,000. Next proof: Gate 8. Gate before selling: Gate 8.

## Product 5 — FounderGate SaaS
- Customer: many founders self-serve. Input: uploaded/connected projects. Output: hosted checks + evidence.
- Proof today: NONE (local-only today). Not built: accounts, tenancy, hosting, billing, security review.
- Must NOT claim: any SaaS availability. Pilot price HYPOTHESIS: subscription (later; not offered now).
- Required next proof: paid proof + security review + deployment. Gate before selling: Gates 9/10 + security + deploy.

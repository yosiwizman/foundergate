# Lane C — First Offer Kit
**Recommended first commercial offer: "FounderGate Safety Check for AI-built MVPs."**
Why first: easiest to explain; lowest liability (read-only, self-owned material, no production
promise); fastest path toward a first PAID engagement (Gate 9); reuses already-proven repo/folder/evidence
capabilities; does not promise production app delivery.

- **Offer name:** FounderGate Safety Check.
- **Buyer:** a founder who built an app with AI tools and isn't sure it actually works / is honest.
- **Pain:** "I have code/a demo but I don't know if it's real, tested, or safe to rely on."
- **Promise:** a founder-readable evidence report on self-owned material — what's proven, what isn't,
  and the next safe step. (NOT a security audit, NOT production sign-off.)
- **Exact deliverables:** a sealed evidence report (project identity, objective, source, checks run,
  result PASS/HOLD/REFUSED/REPAIR, proven vs not-proven, risks, next safe action, blocked actions,
  disclaimer).
- **Excluded:** private/customer/production data; deploy; billing; real integrations; security
  certification; production readiness; anything requiring install without a separate authorization.
- **Price HYPOTHESIS:** $150–$500 (to be validated; nothing charged yet).
- **Intake requirements:** see INTAKE_FORM_SPEC.md (ownership confirmation + authorization required).
- **Evidence output:** the sealed report + evidence index (founder-safe; no raw logs/full SHA to founder).
- **Delivery steps:** intake → classify → read-only checks → evidence → report → deliver. No outreach here.
- **Refund/hold policy:** if the check can't run safely, it HOLDs and is not charged; honest refusal, no fake green.
- **Claim limits:** local evidence only; not production/secure/SaaS/customer/commercial; not paid/market validated.
This kit is a PLAN. No outreach copy to send is created here.
